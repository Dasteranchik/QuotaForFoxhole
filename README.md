1. Открыть файл "quotas.txt"
2. Записать предметы, необходимые для выполнение квоты в формате "[название предмета], [количество ящиков]". Полный список предметов выложен в файле "Список предметов.txt", вписывать названия предметов желательно копируя из файла. Каждый новый предмет записывается в новой строке
3. Сохранить файл "quota.txt"
4. Запустить программу через файл "QuotaForFoxhole.exe"
5. У вас откроется консольное окно, следуйте инструкциям, выводящимся на экране
6. После ввода всех необходимых данных консольное окно самостоятельно закроется
7. Открыть файл "Результат.txt"
8. Радоваться заполненной автоматически квоте
